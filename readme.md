# 🌟 What is ResumeIQ?

**ResumeIQ** is an AI-powered resume–job matching system designed to analyze how well a candidate's resume aligns with a given job description.

Instead of relying on simple keyword matching, ResumeIQ combines multiple layers of analysis:

```text
📄 Resume Parsing
       ↓
🧹 Text Preprocessing
       ↓
🛠️ Skill Extraction
       ↓
🎯 Role Matching
       ↓
⭐ Priority Analysis
       ↓
💼 Experience Analysis
       ↓
🔎 Evidence Detection
       ↓
📐 Similarity Analysis
       ↓
📊 Final Assessment
       ↓
💡 Matching Insights
